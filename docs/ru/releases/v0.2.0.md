# Fiml 0.2.0

Выпуск добавляет композицию средних, предвычисленный контекст, обучающие цели по
времени и управление хранилищем стакана/свежестью источника.

<a id="highlights"></a>

## Основные возможности

- SMA/EMA по отсчётам применяются к исходным полям и другим признакам в этапах,
  включая стакан. Их продвигают только конечные наблюдения источника.
- Предвычисленный контекст с атомарными обновлениями и расписанием при
  воспроизведении/обучении Python.
- Офлайн-метки `future_value` с направлением, допуском и деталями совпадений.
- Плотное заранее выделенное хранилище стакана на ограниченной десятичной сетке.
- Доступ в Rust к синхронизации, исходным меткам, результатам стакана по событиям,
  наблюдениям источников и маскам конвейера для отделения возраста от готовности.
- Новый Python-пример воспроизведения записи частичной глубины Binance.

<a id="migration-from-010"></a>

## Миграция с 0.1.0

SMA/EMA по отсчётам теперь преобразования. Замените их в экстракторе исходными
полями и этапами; отдельные калькуляторы и временная SMA сохранены.
Исходные ID/раскладки меняются; задайте явные выходные ID для стабильных столбцов.

JSON экстрактора — **2.0**, конвейера — **3.0**. Старые артефакты отклоняются.
Пересоздайте и экспортируйте по
[руководству](https://github.com/pbezglasny/fiml/blob/v0.2.0/docs/sample-average-migration.md).

Второй аргумент `OrderBook::apply_update` Rust — исходная Unix-метка миллисекунд.
`OrderBookConfig::build()` возвращает `Result`; литералам нужно поле `dense`,
предпочитайте `OrderBookConfig::new(...)`. `FeatureKey` больше не `Copy`:
заимствуйте/клонируйте явно. Другие изменения типов — в
[журнале](https://github.com/pbezglasny/fiml/blob/v0.2.0/CHANGELOG.md).

<a id="support-and-limits"></a>

## Поддержка и ограничения

Нужны Rust **1.89+** или CPython **3.12+**. Wheel по-прежнему Linux
x86-64/AArch64, macOS x86-64/AArch64, Windows x86-64. Apache-2.0.
Для `future_value` нужен набор `pandas`.

JSON хранит конфигурацию/параметры. После загрузки воспроизведите прогрев и задайте
контекст. Истечение контекста и свежесть — политики вызывающего кода. Память плотного
стакана растёт с числом тиков диапазона; по умолчанию хранилище разреженное.
Генерируйте цели отдельно по инструменту и хронологической части данных.
