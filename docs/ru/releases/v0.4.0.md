# Fiml 0.4.0

Дата выпуска: 2026-10-28.

Дельты стакана теперь поддерживают включительные диапазоны ID обновлений,
в том числе агрегированные обновления потока, перекрывающие следующий требуемый
ID. Выпуск включает [PR #207](https://github.com/pbezglasny/fiml/pull/207)
и документацию выпуска.

<a id="order-book-updates"></a>

## Обновления стакана

- Для обновлений, охватывающих несколько ID, используйте
  `OrderBookDelta::new_range`, `OrderBookUpdate::new_delta_range` или Python
  `OrderBookEvent.delta_range`.
- `Contiguous` принимает диапазон, покрывающий следующий требуемый ID, при прямом
  применении и воспроизведении буфера после снимка. Начало диапазона после этого
  ID по-прежнему означает пропуск; диапазоны, заканчивающиеся не позже последнего
  применённого ID, считаются устаревшими.
- Размеры уровней остаются абсолютными величинами; ноль удаляет уровень.
- Обратные границы возвращают `OrderBookUpdateError::InvalidUpdateRange` при
  применении в Rust или `ValueError` при создании события в Python.

<a id="migration-from-030"></a>

## Миграция с 0.3.0

В Rust замените `OrderBookDelta.update_id` в обращениях к полям и литералах
структур на `first_update_id` и `final_update_id`. Используйте `final_update_id`,
если старое поле представляло последний применённый ID. Добавьте
`InvalidUpdateRange` в исчерпывающие сопоставления `OrderBookUpdateError`.

```rust
use fiml::order_book::OrderBookDelta;

fn main() {
    let single = OrderBookDelta::new(101, vec![]);
    assert_eq!((single.first_update_id, single.final_update_id), (101, 101));

    let batch = OrderBookDelta::new_range(101, 105, vec![]);
    assert_eq!((batch.first_update_id, batch.final_update_id), (101, 105));
}
```

Вызовы `OrderBookDelta::new(id, changes)`,
`OrderBookUpdate::new_delta(id, changes)` и Python `OrderBookEvent.delta(...)`
по-прежнему поддерживаются и устанавливают обе границы равными переданному ID.

```python
from fiml import OrderBookEvent

single = OrderBookEvent.delta(
    "BTCUSDT", timestamp=1000, update_id=101,
    changes=[("bid", "100", "2")],
)
batch = OrderBookEvent.delta_range(
    "BTCUSDT", timestamp=1001, first_update_id=102, final_update_id=105,
    changes=[("bid", "100", "3")],
)
```

JSON экстрактора остаётся `2.0`, а JSON конвейера — `4.0`; артефакты конфигурации
0.3.0 не требуют миграции формата или повторного обучения для этого выпуска.
ID признаков и раскладка выходов не изменились. JSON по-прежнему не содержит
текущее состояние; после загрузки воспроизведите прогрев и заново задайте контекст.

<a id="installation-and-support"></a>

## Установка и поддержка

```bash
cargo add fiml@0.4.0 --features serde
python -m pip install "fiml[pandas]>=0.4.0,<0.5"
```

Нужны Rust **1.89+** или CPython **3.12+**. Wheel доступны для Linux x86-64/AArch64,
macOS x86-64/AArch64 и Windows x86-64. NumPy обязателен; наборы `pandas` и
`sklearn` остаются необязательными. Лицензия Apache-2.0.

См. [журнал изменений](https://github.com/pbezglasny/fiml/blob/v0.4.0/CHANGELOG.md)
и [список проверок выпуска](https://github.com/pbezglasny/fiml/blob/v0.4.0/docs/release-check-list.md).
