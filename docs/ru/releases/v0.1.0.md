# Fiml 0.1.0

Первый выпуск Fiml: создавайте торговые признаки по истории в Python и запускайте
тот же конвейер на живых событиях в Rust.

<a id="highlights"></a>

## Основные возможности

- Потоковые доходности, SMA/EMA, скользящая волатильность, число/объём сделок,
  VWAP, CVD, OBV, VPT, календарные признаки.
- Воспроизведение снимков/дельт стакана с котировками, спредом, глубиной и дисбалансом.
- Переиспользуемые векторы Rust, воспроизведение NumPy и необязательный pandas.
- Переносимые определения JSON. Обучайте поддерживаемую предобработку scikit-learn
  в Python, исполняйте параметры в Rust: масштабирование, заполнение,
  степенные/квантильные преобразования, отбор, PCA.

<a id="support-and-limits"></a>

## Поддержка и ограничения

Нужны Rust **1.89+** или CPython **3.12+**. Wheel: Linux x86-64/AArch64,
macOS x86-64/AArch64, Windows x86-64. Лицензия Apache-2.0.

Прогрев/недоступность могут давать `NaN`. Миллисекундные метки не убывают для
символа. JSON загружается с пустой историей; перед применением воспроизведите
прогрев. Создание, преобразование выходов Python и стакан могут выделять память.

До `1.0` минорные выпуски могут быть несовместимыми, патчи — совместимые исправления.
