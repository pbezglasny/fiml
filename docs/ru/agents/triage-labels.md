# Метки разбора задач

Навыки используют пять канонических ролей. Таблица сопоставляет их фактическим
строкам меток трекера этого репозитория.

| Метка mattpocock/skills | Метка нашего трекера | Значение |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Сопровождающий должен оценить задачу |
| `needs-info` | `needs-info` | Ожидается информация от автора |
| `ready-for-agent` | `ready-for-agent` | Полностью определено, готово автономному агенту |
| `ready-for-human` | `ready-for-human` | Нужна реализация человеком |
| `wontfix` | `wontfix` | Выполняться не будет |

Если навык упоминает роль (например, метку готовности автономному агенту), используйте
соответствующую строку таблицы.

Изменяйте правый столбец под фактически используемую терминологию.
