# ADR 0007: Закрытая среда исполнения экстрактора

Статус: принято\
Дата: 2026-08-11

<a id="context"></a>

## Контекст

Слой признаков Rust предоставлял публичный трейт обновления `Feature<F>`, enum
`BuiltinFeature` и адаптеры вроде `SmaFeature`. Документация предлагала оборачивать
адаптеры своим enum для пользовательских признаков.

Этот путь не работал с экстракторами библиотеки. Компиляция принимала только
варианты библиотечного `IndicatorSpec` и создавала `BuiltinFeature`.
`IndicatorFeatureVector` хранил конкретный enum; ни компиляция, ни создание не
принимали сторонний enum. Типы рекламировали неподдерживаемую настройку и делали
внутренние контракты адаптеров частью API.

До выпуска эту поверхность допустимо удалить без совместимых обёрток.
Экстрактор фиксированной ёмкости и отдельные калькуляторы решают другие задачи
памяти/композиции и не должны удаляться вместе с неподдерживаемым расширением.

<a id="decision"></a>

## Решение

Экстракторы поддерживают закрытый набор библиотечных вариантов `IndicatorSpec`.
Новый индикатор нужно добавить в определения, компиляцию, сериализацию,
построитель и создание вектора признаков.

Публичный `Feature<F>` удаляется. Внутренний enum переименовывается из
`BuiltinFeature` в `IndicatorFeaturesEnum` с собственным методом обновления.
Он и адаптеры — детали `features/builtin/`, недоступные для именования/создания
сторонними crate.

`IndicatorFeatures` остаётся общим интерфейсом `FeatureExtractor` и
`IndicatorFeatureVector`, но закрывается для сторонних реализаций. Публичность
сохраняет общие методы и позволяет `Pipeline` принимать обе библиотечные формы.

`IndicatorFeatureVector` остаётся публичным с фиксированной ёмкостью индикаторов
и выбираемым вызывающим кодом хранилищем для встроенного набора. Калькуляторы
`fiml::indicators` тоже публичны и компонуются вне экстрактора.

Устаревших псевдонимов, адаптеров совместимости, callbacks и динамических
расширений через trait object не остаётся.

<a id="consequences"></a>

## Последствия

- API описывает реально поддерживаемую настройку через `FeatureExtractorSpec`
  и `IndicatorSpec`.
- Диспетчеризация статична и не выделяет память на событие.
- Фиксированные и динамически размеренные экстракторы работают с `Pipeline`.
- Пользователь может компоновать отдельные расчёты, но не внедрять их в
  спецификацию, компилятор и конвейеры как свой экстрактор.
- Импорты `Feature`, `BuiltinFeature` и адаптеров перестают компилироваться;
  нужен переход к настройке или отдельным индикаторам.
- Семантика, имена, JSON, Python и выход построителя не меняются.

Это уточнение границы адаптеров ADR 0002 без изменения группировки, компиляции
и контракта памяти.
