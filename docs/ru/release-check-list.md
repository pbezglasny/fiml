# Список проверок выпуска 0.4.0

Целевой тег: `v0.4.0`. Пакеты Rust и Python выпускаются вместе 2026-10-28.
Предыдущий выпуск [v0.3.0](https://github.com/pbezglasny/fiml/releases/tag/v0.3.0)
опубликован 2026-10-24 из `a1fcacc4c3954793000572c827ccfb01852aa1d1`.

<a id="release-records"></a>

## Документы выпуска

- [x] Установить `0.4.0` в обоих Cargo-манифестах; Python берёт версию из
  манифеста привязок. Сохранить политику игнорирования Cargo.lock.
- [x] Описать диапазоны обновлений стакана и миграцию Rust в
  [CHANGELOG.md](CHANGELOG.md) и [описании выпуска](releases/v0.4.0.md).
- [x] Обновить руководства по установке и русские переводы, включая индекс.
  Указать дату выпуска в обоих журналах изменений и описаниях выпуска.
- [x] Сохранить Rust 1.89, CPython 3.12+, пять целевых платформ wheel,
  JSON экстрактора `2.0` и JSON конвейера `4.0`.

<a id="candidate-validation"></a>

## Проверка кандидата

Записать SHA кандидата, команды, ссылки на запуски workflow, состав артефактов
и результаты чистых установок в PR выпуска. Флажки описывают обязательную
процедуру; PR и результаты workflow подтверждают конкретный коммит.
Не переносить результаты проверок 0.3.0. Новый коммит требует повторной проверки.

- [ ] `cargo fmt --all -- --check`
- [ ] `cargo +1.89.0 test --all-features`
- [ ] `cargo +1.89.0 clippy --workspace --all-targets --all-features -- -D warnings`
- [ ] `RUSTDOCFLAGS="-D warnings -D missing_docs" cargo +1.89.0 doc -p fiml --all-features --no-deps`
- [ ] `RUSTUP_TOOLCHAIN=1.89.0 just test-python`
- [ ] `RUSTUP_TOOLCHAIN=1.89.0 just test-notebook`
- [ ] Выполнить обычный CI для PR и запустить `ci.yml` вручную для ветки
  кандидата; все проверки должны пройти, а `head_sha` ручного запуска —
  совпасть с кандидатом.
- [ ] Запустить `release.yml` на том же коммите без публикации; все задания
  упаковки и тесты API Linux wheel должны пройти.
- [ ] Проверить семь артефактов: crate, sdist и wheel для Linux x86-64/AArch64,
  macOS x86-64/AArch64, Windows x86-64. Проверить версии, ABI-теги,
  метаданные, README/лицензию и необходимые исходники.
- [ ] Установить скачанные Linux x86-64 wheel и sdist в отдельные чистые
  окружения CPython 3.12. Выполнить быстрые примеры, примеры миграции стакана
  и воспроизведение именованных выходов Python → Rust со скачанным crate.

<a id="tagging-and-publishing"></a>

## Тег и публикация

Отправка `v0.4.0` запускает `.github/workflows/release.yml`, который публикует
пакеты в crates.io и PyPI, затем создаёт GitHub release с семью артефактами
и текстом из `docs/releases/v0.4.0.md`. Не загружать пакеты вручную заранее.

- [ ] Слить PR выпуска после успешных проверок. Убедиться, что дерево после
  слияния совпадает с проверенным кандидатом и CI итогового коммита прошёл.
- [ ] Подтвердить доступность учётных данных публикации, поставить `v0.4.0`
  на проверенный коммит выпуска и отправить тег.
- [ ] Проверить workflow публикации, оба реестра и все семь артефактов
  GitHub release: везде должна быть версия `0.4.0`.
- [ ] Проверить чистые установки `cargo add fiml@0.4.0` и
  `pip install fiml==0.4.0`, а также API диапазонов обновлений стакана.
