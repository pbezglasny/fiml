<a id="current-architecture"></a>

## Текущая архитектура

Извлечение имеет один поток компиляции:

```text
FeatureDefinition / FeatureKey
    -> FeatureExtractorBuilder or FeatureExtractorSpec
    -> feature compiler
    -> FeatureExtractor
```

`FeatureDefinition` описывает одну скалярную ячейку. При компиляции совместимые
определения (например, средние с несколькими окнами) группируются в одно вычисление
с непрерывным выходным диапазоном.

`FeatureExtractorSpec` — версионированная граница конфигурации/сериализации.
Владеет каноническими скалярными определениями, полной шириной модели и
необязательным checksum. При `serde` преобразуется в строгий групповой JSON
и обратно без публичных типов внешнего представления.

`FeatureExtractor<F, V>` владеет:

- выбранным `V: FeatureVector`;
- статически диспетчеризуемыми `FeatureDerivation`;
- диапазонами и стабильными ID;
- маршрутизатором символ/событие;
- порядковым временем по символу, последним поступлением и максимальной меткой
  для глобального календаря.

Обработка событий не выделяет память. Маршруты — готовые массивы и плоские списки,
вычисления пишут прямо в вектор.

## Завершённая работа

- Старые `IndicatorSpec`, `ScopedIndicator`, `TimeWindows`, `ValueSource` заменены
  скалярными `FeatureDefinition`, `FeatureKey`, `FeatureSource`, `EventField`.
- `FeatureExtractorSpec` пересоздан как версионированная каноническая конфигурация
  с тем же компилятором, что у цепочечного Rust-построителя.
- Добавлена строгая сериализация под `serde`: все текущие ключи, внешний контракт,
  сохранение ёмкости/checksum.
- Компилятор стал единственным путём от определений к вычислениям/маршрутам.
- Разделение фиксированного вектора индикаторов и динамического экстрактора
  заменено generic `FeatureExtractor<F, V>`.
- Добавлен `VecFeatureVector` с размером при исполнении рядом с `ArrayFeatureVector`.
- Python перенесён на новые спецификацию/компилятор/экстрактор. Цепочечные групповые
  вызовы разворачиваются в скалярные определения с прежними именами и порядком.
- Сохранены предварительная проверка пакета, транзакционное воспроизведение,
  выбор dtype, начальные NaN недоступных/резервных ячеек.
- Восстановлены исходники конвейера/преобразований. Преобразования компилируются,
  старый конвейер исключён из `features/mod.rs` до решения API и согласованности.
- Добавлены отдельные виды дельты/снимка стакана, конструкторы и маршрутизация Rust.
- Удалены старый экстрактор, устаревшие примеры и замер.
- Примеры Rust переведены на `FeatureExtractor`, добавлен JSON-пример и явные Cargo-цели.
- Добавлено детерминированное воспроизведение сделок с CSV в репозитории:
  SMA/EMA цены, SMA объёма сделки, CVD, временное число сделок. Столбцы из
  `feature_ids()`, проверяются схема, NaN прогрева, порядок, число строк и финальные значения.
- `docs/project-schema.md` обновлён под архитектуру.

<a id="available-feature-derivations"></a>

## Доступные вычисления признаков

Компилятор поддерживает:

- простое среднее;
- экспоненциальное среднее;
- накопленную дельту объёма;
- временное простое среднее;
- временной балансовый объём;
- временное число сделок;
- день недели;
- время с первого события локального дня.

Средние читают цену, объём, цену/объём сделки. Торговые индикаторы подписаны на
полные сделки. Временные вычисления получают каждое принятое событие своего
символа, даже без отсчёта. Глобальный календарь обновляется не раньше максимальной метки.

<a id="known-gaps-and-deliberate-boundaries"></a>

## Известные пробелы и намеренные границы

- Старый конвейер рассчитан на удалённые `IndicatorFeatures`/
  `IndicatorFeatureVector`, не объявлен в `features/mod.rs`. Механический перенос
  не решает сериализацию и совпадение Rust/Python.
- `StandardScaler`, `ParallelTransformer` только в Rust. Преобразования не входят
  в спецификацию, артефакт и привязки Python.
- Загрузчика истории конкретной биржи нет.
- Метки и обучение моделей вне основного API.
- Несколько живых источников нужно объединить в глобально неубывающем порядке до экстрактора.
- Rust принимает дельты/снимки, но стакан не подключён к признакам. Python пока
  принимает только дельты.
- Экстрактор намеренно компилирует закрытые библиотечные `FeatureKey`/
  `FeatureDerivation`; пользовательские вычисления не поддерживаются.

## Рекомендуемая следующая реализация

межъязыковой артефакт. Определить сериализацию, одинаковый порядок вычислений и раскладки.

преобразование `Decimal` стакана в `Float` экстрактора.
