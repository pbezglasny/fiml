# Словарь предметной области

<a id="trade-dataframe"></a>

## DataFrame сделок

Уже загруженный pandas DataFrame в порядке поступления с неубывающим временем
по символу. Четыре выбранных столбца содержат символ, миллисекунды эпохи, цену и
объём сделки. Файловые форматы и хранение вне границ `fiml`.

<a id="feature-vector-snapshot"></a>

## Снимок вектора признаков

Полное упорядоченное числовое состояние экстрактора сразу после события.
`compute_features` выдаёт один снимок на сделку.

<a id="event-kind"></a>

## Вид события

Рыночный поток, потребляемый маршрутизируемым признаком: цена, объём или сделка.
SMA/EMA записывают вид события в артефакт согласованности спецификации; признак
обновляется только событием этого вида.

<a id="metadata-columns"></a>

## Столбцы метаданных

Символ и время, копируемые из DataFrame сделок в таблицу снимков. Они идентифицируют
снимок, но не входят в `feature_names()` и `n_features()`.

<a id="per-symbol-timestamp-watermark"></a>

## Временная граница символа

Метка последнего принятого события символа по всем видам. Следующее событие
символа должно иметь равное или большее время. Rust `last_timestamp()` показывает
последнее поступление и может уменьшаться между символами;
`last_timestamp_for_symbol(Symbol)` — границу порядка. Глобальные календарные
признаки следуют отдельной максимальной принятой метке.

<a id="calculation-dtype"></a>

## Тип вычислений

Представление `float64` состояния/расчётов индикаторов, неизменное за жизнь экстрактора.

<a id="output-dtype"></a>

## Тип выхода

`float32` или `float64` массивов и столбцов Python. Настраивается только до
обработки первого события.

<a id="indicator-definition"></a>

## Определение индикатора

Одно пользовательское описание рабочего экземпляра. Определение с привязкой к
символу содержит имя и спецификацию. Группа содержит несколько упорядоченных
окон выходов, реализованных одним состоянием расчёта.

<a id="indicator-identity"></a>

## Идентичность индикатора

Поля, определяющие один рабочий индикатор: символ при наличии, тип, настраиваемый
источник и временная агрегация. Выходные окна не входят. Повтор идентичности
недопустим: определения нужно объединить.

<a id="output-span"></a>

## Диапазон выходов

Непрерывные ячейки одного скомпилированного индикатора: начальный индекс и число.
Выход `i` пишет в `start + i`, порядок совпадает с порядком окон пользователя.

<a id="value-source"></a>

## Источник значения

Точное поле события для среднего: отдельная цена, отдельный объём, цена сделки,
объём сделки. Определяет и маршрут, и извлекаемое числовое поле.

<a id="time-windows"></a>

## Временные окна

Общее определение временного индикатора с одной длительностью агрегации и
упорядоченными длительностями скользящих окон. Окно — ненулевое точное кратное
агрегации, помещающееся в знаковые 64-битные миллисекунды.

<a id="rolling-volatility"></a>

## Скользящая волатильность

Стандартное отклонение генеральной совокупности соседних простых доходностей
`(current - previous) / previous`. Окна по отсчётам считают доходности. Временные
относят доходность к интервалу нового наблюдения и хранят точные число, среднее и
центральные моменты на интервал. Нулевая предыдущая цена задаёт новую базу,
поскольку процентная доходность не определена.

<a id="sample-returns"></a>

## Доходности по отсчётам

Простые: `(current - lagged) / lagged`; логарифмические: `ln(current) - ln(lagged)`.
Лаг считает подходящие отсчёты источника. До `lag + 1` отсчётов выход отсутствует.
Нулевое прошлое значение делает простую доходность недоступной, неположительный
любой конец — логарифмическую.

<a id="canonical-feature-name"></a>

## Каноническое имя признака

Глобально уникальное имя библиотеки по символу, источнику, типу и параметрам выхода.
Сегменты разделены двоеточиями, разделители в символах экранируются. Канонические
имена — единственные, пока не появится конкретная потребность в псевдонимах.

<a id="output-count"></a>

## Число выходов

Число ячеек, создаваемых спецификацией. Отличается от числа индикаторов, поскольку
одна группа может владеть несколькими соседними выходами.

<a id="indicator-count"></a>

## Число индикаторов

Число определений и, следовательно, рабочих экземпляров в скомпилированной спецификации.

<a id="compilation"></a>

## Компиляция

Процесс вне горячего пути: проверка упорядоченного `FeatureExtractorSpec`, генерация
имён/диапазонов, создание адаптеров и перенос в хранилище фиксированной ёмкости.
Временные метаданные могут выделять память; диспетчеризация событий — нет.

<a id="indicator-adapter"></a>

## Адаптер индикатора

Внутреннее рабочее значение связывает отдельный расчёт с маршрутом, символьной/
глобальной областью, источником и выходным диапазоном. Закрытый enum принадлежит
библиотеке, не служит точкой расширения. Один адаптер представляет один индикатор
и может писать несколько соседних ячеек.

<a id="global-clock-feature"></a>

## Глобальный признак часов

Признак по времени любого события, а не рыночным полям символа. День недели и
время с первого события локального дня — такие признаки. Обновляются только на
максимальной принятой метке или позже.

<a id="time-since-first-event-of-day"></a>

## Время с первого события дня

Миллисекунды с первого наблюдения после границы дня при фиксированном UTC-смещении.
Это не расчёт открытия сессии по календарю биржи.

<a id="runtime-allocation-boundary"></a>

## Граница выделения памяти

Конфигурация, метаданные, генерация имён и компиляция могут выделять память.
Экстрактор выделяет состояние заранее; диспетчеризация, обновления и запись ячеек
не выделяют память на событие.

<a id="warm-up-policy"></a>

## Политика прогрева

Правило готовности оконного выхода. `FirstValue` готов после первого подходящего
входа. `FullWindow` — после нужного числа подходящих входов или покрытия полной
длительности временного окна временем событий символа. Одна политика на группу,
но каждый выход готов по собственному окну.

<a id="indicator-readiness"></a>

## Готовность индикатора

Монотонное состояние завершения прогрева выхода, сохраняемое до сброса/пересоздания.
Независимо от наличия значения: прогретая временная SMA с пустым окном остаётся
готовой, но выдаёт пропуск.

<a id="missing-feature-value"></a>

## Отсутствующее значение признака

Выход без текущего числового значения. Отдельный индикатор представляет его `None`,
ячейка с плавающей точкой — NaN. Сюда входят прогрев и пустое окно прогретого
временного среднего. Временные счётчики и накопительные значения используют ноль
для наблюдаемого пустого окна.
