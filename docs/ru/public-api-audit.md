# Аудит публичного API Rust для v0.1.0

Дата: 2026-09-15\
Коммит: `b637bab`\
Статус: граница принята, все четыре замечания исправлены.

Экстрактор скрывает компилятор, маршруты, вычисления и исполнение преобразований.
Отдельные индикаторы публичны и поддерживают явное время событий.

<a id="resolved-findings"></a>

## Исправленные замечания

1. **Счётчик сделок:** `TradeCountTimed::update(timestamp)` публичен; сторонний
   код может создать, заполнить и прочитать счётчик.
2. **Временные обновления/истечение:** OBV и VWAP принимают
   `update(price, volume, timestamp)`, объём — `update(volume, timestamp)` вместо
   обёрток системных часов. Все шесть временных типов имеют `observe(timestamp)`
   для истечения/прогрева без данных. Экстрактор и пакетные помощники вызывают те
   же методы. Документация описывает конечные входы и неубывающее время; чтение
   время не продвигает.
3. **Лишний экспорт стакана:** `SyncState` приватен в `book.rs`, больше не
   реэкспортируется. Результаты обновлений и ошибки публичны.
4. **Недостижимые объявления:** `EmaWindow`, `SmaWindow` приватны. `LaggedFeature`
   имеет `pub(crate)` из-за использования в доступном crate enum `Transformer`;
   конструктор и `apply` — `pub(super)`. Сторонним пользователям типы не экспортируются.

Изменение временных сигнатур и удаление `SyncState` — намеренные несовместимости
до первого выпуска.

<a id="accepted-public-boundary"></a>

## Принятая публичная граница

| Поверхность | Решение |
| --- | --- |
| События, данные, символы, прогрев | Публичны: создание входов и настройка. |
| Ключи, ID, определения, построитель, экстрактор, спецификации | Публичны: поддерживаемая настройка/исполнение. |
| Конвейер, спецификация, определения преобразований, обученные этапы | Публичны: передача обученного состояния и чтение входов модели. |
| FeatureVector, массивы/кучевое хранилище | Публичны: выбор хранилища — предусмотренное расширение. |
| Отдельные индикаторы и пакетные помощники | Публичны с явным временем, сохраняя ADR 0007. |
| RingBuffer, стековые/кучевые буферы, конструкторы, интервальные типы | Публичны: видны в сигнатурах индикаторов. Поля интервалов приватны. |
| Настройка стакана, обновления, запросы, результаты, ошибки | Публичны; SyncState внутренний. |
| Ошибки и вспомогательные enum | Публичны для разбора сбоев. |
| MAX_OUTPUTS_PER_INDICATOR, symbols::MAX_SYMBOL_NUMBER | Публичны как действующие ограничения. |
| Компилятор, вычисления, маршруты, подготовленные обновления, рабочие этапы | Внутренние; текущая граница это обеспечивает. |

Сохранить пути `event`, `features`, `indicators`, `order_book`, `symbols` и корневые
реэкспорты. Удаление повторных путей лишь создаст изменения без сокрытия состояния.

<a id="verification"></a>

## Проверка

Внешний интеграционный тест
[`standalone_timed_indicators.rs`](../../crates/fiml/tests/standalone_timed_indicators.rs)
создаёт все шесть типов публичным API и проверяет историю, прогрев продвижением
времени, обновление на уже наблюдавшейся метке и повторное истечение без отсчётов.

После реализации прошли:

- Форматирование: `cargo fmt --all -- --check`.
- Workspace: `cargo test --workspace --all-features --offline` (254 теста, 1 doctest).
- Clippy: `cargo clippy --workspace --all-targets --all-features --offline -- -D warnings`.
- Документация: `RUSTDOCFLAGS="-D warnings -D missing_docs" cargo doc -p fiml --all-features --no-deps --offline`.
- Видимость: `cargo rustc -p fiml --lib --all-features --offline -- -D unreachable_pub`.

Аудит охватил сигнатуры, реэкспорты и использование в Python, примерах, интеграционных
тестах, замерах и проектных записях. Полного аудита численной корректности и
производительности не было.
