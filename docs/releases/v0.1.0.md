# Fiml 0.1.0

First release of Fiml: build trading features from historical data in Python
and run the same feature pipeline on live events in Rust.

## Highlights

- Streaming returns, SMA/EMA, rolling volatility, trade count and volume,
  VWAP, CVD, OBV, VPT, and calendar features.
- Order-book snapshot/delta replay with quote, spread, depth, and imbalance
  features.
- Reusable Rust feature vectors, NumPy event replay, and optional pandas input.
- Portable JSON feature and pipeline definitions. Fit supported scikit-learn
  preprocessing in Python and execute the exported parameters in Rust,
  including scaling, imputation, power/quantile transforms, selection, and PCA.

## Support and limits

Requires Rust **1.89+** or CPython **3.12+**. Python wheel targets are Linux
x86-64/AArch64, macOS x86-64/AArch64, and Windows x86-64. Licensed Apache-2.0.

Warm-up and unavailable values can produce `NaN`. Events must have
nondecreasing millisecond timestamps per symbol. Loading JSON starts with
empty event history; replay a warm-up prefix before inference. Construction,
Python output conversion, and order-book storage may allocate.

Before `1.0`, minor releases may contain breaking changes; patch releases are
for compatible fixes. See the [changelog](https://github.com/pbezglasny/fiml/blob/v0.1.0/CHANGELOG.md)
for the full feature list, limits, and compatibility policy, and the
[README](https://github.com/pbezglasny/fiml/blob/v0.1.0/README.md) for examples.
